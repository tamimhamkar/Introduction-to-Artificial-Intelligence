# Assignment 11: Image Classification Using Random Forest

## Overview
In this project, I used Random Forest to classify images into five categories: Dalmatian, Dollar Bill, Pizza, Soccer Ball, and Sunflower.

## What I Did
- Loaded and resized the images
- Normalized the pixel values
- Split the data into training and testing sets
- Used GridSearchCV to tune the Random Forest model
- Evaluated the model using accuracy, precision, recall, and F1 score
- Created a confusion matrix
- Visualized feature importance
- Tested the model on an image

## Results
The Random Forest model achieved about **77.42% accuracy** on the test data.

## How to Run
1. Open the notebook in Google Colab.
2. Upload `images.zip`.
3. Run the cells in order.
