# Assignment 13: Generative AI Essentials

## About This Project

In this assignment, I explored the basics of Generative AI and learned how a simple text generation model can create new text based on patterns it learns from existing data.

I used *Alice's Adventures in Wonderland* by Lewis Carroll from Project Gutenberg as my text dataset.

## What I Did

- Loaded a public text dataset from Project Gutenberg
- Prepared and converted the text into numerical data
- Created training sequences
- Built a text generation model using TensorFlow/Keras
- Used Embedding and LSTM layers
- Trained the model for 5 epochs
- Created training and validation graphs
- Generated new text using the seed text "Alice was"
- Reviewed the model's results and overfitting
- Explained how GPT architecture works
- Discussed ethical concerns related to Generative AI
- Demonstrated how text generation can be used for creative writing

## Results

The model reached about **77.49% training accuracy** and **54.56% validation accuracy**.

The model was able to generate new text, although some sentences and words were not always clear. This showed me that a simple model can learn patterns from text, but the quality of generated content depends on the model, training, and dataset.

1. Open the notebook in Google Colab.
