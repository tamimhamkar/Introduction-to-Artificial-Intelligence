# Assignment 9: Unsupervised Learning

This project uses the Iris dataset to explore unsupervised learning techniques, including K-Means Clustering, Hierarchical Clustering, and Principal Component Analysis (PCA).

## Methods Used
- Data preprocessing and feature scaling
- K-Means Clustering
- Hierarchical Clustering
- Elbow Method
- Silhouette Score
- Principal Component Analysis (PCA)
- Cluster visualization

## Results
K-Means achieved a Silhouette Score of 0.581, while Hierarchical Clustering achieved 0.576. K-Means performed slightly better and was selected as the best clustering model.

PCA reduced the original four features to two principal components while retaining approximately 95.85% of the information.

## How to Run
Open the notebook in Google Colab and run all cells from top to bottom.

## Requirements
Python, pandas, NumPy, Matplotlib, Seaborn, SciPy, and Scikit-learn.
