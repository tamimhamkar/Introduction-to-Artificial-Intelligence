# Assignment 12: Neural Network and Deep Learning Basics

## About This Project

In this project, I used a neural network to classify clothing images from the Fashion MNIST dataset. The goal was to learn how a basic neural network can recognize different types of clothing.

## What I Did

- Loaded and explored the Fashion MNIST dataset
- Displayed sample images from the 10 clothing categories
- Normalized the image pixel values
- Built a feedforward neural network using ReLU and Softmax
- Trained the model for 10 epochs
- Evaluated the model using accuracy, precision, recall, and F1-score
- Created training and validation graphs
- Created a classification report and confusion matrix
- Tested a larger neural network and compared the results

## Results

The original neural network achieved **88.16% test accuracy**.

I also tested a larger neural network, which achieved **87.68% accuracy**. This showed that adding more layers and neurons did not necessarily improve the model.
